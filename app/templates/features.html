CURRENT SCOPE

What AcaSift does not currently do

Clear scope helps users interpret results appropriately and understand what is not covered by the current release.

  • It does not search the entire internet or commercial academic databases.
  • It does not process scanned, image-only PDFs using OCR.
  • It does not currently perform semantic paraphrase detection or cross-language comparison.
  • It does not compare source code.
  • It does not automatically decide whether plagiarism or academic misconduct has occurred.
Supported file size

The current application upload limit is 15 MB per file. Scanned PDFs without an extractable text layer are not supported.
