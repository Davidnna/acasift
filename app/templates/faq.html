What is AcaSift?

AcaSift is an academic document similarity analysis platform. It compares uploaded submissions against documents in an administrator-curated reference repository, identifies textual overlap and presents source-level results for review.

Does AcaSift search the entire internet?

No. The current release compares submissions against reference documents stored in its internal repository. It does not perform internet-wide searches or query commercial academic publication databases.

Does a similarity score mean that plagiarism has occurred?

No. A similarity score measures textual similarity under the implemented comparison method. It is not a percentage of plagiarised content and does not establish academic misconduct. Quotations, references, common terminology and other legitimate overlap can affect results.

Which file formats are supported?

The current release supports PDF, DOCX and TXT files, with a maximum upload size of 15 MB per file.

Can AcaSift analyse scanned PDFs?

Not in the current release. Scanned or image-only PDFs need optical character recognition (OCR), which is not currently included. The PDF must contain extractable text.

How does AcaSift identify matching passages?

It tokenises text and checks for shared word-based N-gram sequences. It also calculates TF-IDF cosine similarity to provide a document-level similarity indicator.

Can AcaSift detect paraphrased content?

The current release does not provide semantic paraphrase detection. Its passage matching is based on exact word sequences, while TF-IDF cosine similarity reflects weighted term overlap.

How do I create an account?

Self-service registration is not currently available. Accounts are created by an authorised AcaSift administrator. If your institution uses AcaSift, contact the person responsible for administering the platform.

Who can add reference documents?

Only users with the administrator role can add documents to the reference repository and create user accounts.

What should I do if no sources appear in my report?

The repository may not yet contain any processed reference documents, or no available reference document may have produced a comparison result. Contact your AcaSift administrator about the reference collection.

Need access to AcaSift?

Accounts are issued by an authorised administrator. Read the access information or proceed to the sign-in page if you already have an account.
