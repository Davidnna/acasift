HOW IT WORKS

A straightforward path
from upload to review.

AcaSift follows a defined process: prepare reference documents, submit a document, compare the text and inspect the resulting report.

01
ADMINISTRATOR SETUP

Build the reference repository

An authorised administrator uploads reference documents in PDF, DOCX or TXT format. AcaSift extracts and stores their text so they can be used as comparison sources.

TEXT COMPARISON

Compare against available sources

AcaSift calculates TF-IDF cosine similarity and checks for shared word-based N-grams between the submitted document and the reference documents available in the repository.

REPORT AND HUMAN REVIEW

Inspect the results in context

The report lists compared sources, similarity indicators and matching passages. A reviewer examines the original context, quotations, references and citations before reaching a conclusion.

INTERPRETING THE REPORT

Results require academic judgement.

Cosine similarity is not a plagiarism percentage. Matching text may be properly quoted or cited, and common language can occur independently. Use the report as a starting point for review.
