ABOUT ACASIFT

Supporting thoughtful
academic document review.

AcaSift is an academic document similarity analysis platform designed to help users examine textual overlap between submitted work and a curated collection of reference documents.

OUR PURPOSE

Make textual similarities easier to examine.

Reviewing academic work can involve comparing a submission with existing materials, identifying similar passages and examining the context in which those passages appear. AcaSift brings these tasks together in a web-based workflow.

The platform extracts text from supported documents, compares the extracted content against reference documents stored in its repository, and presents document-level similarity indicators and identified matching passages.

AcaSift is intended to support students, educators and academic administrators in a careful review process. It does not replace citation checks, expert assessment or institutional academic-integrity procedures.

OUR APPROACH

Clarity, context and responsible interpretation.

01

Transparent methods

Similarity results are based on identifiable text-comparison methods and a defined reference collection.

02

Source-aware review

Reports connect identified overlaps to the reference document in which the matching text was found.

03

Human judgement

Results are review aids. People must interpret quotations, citations, common phrases and source context.

Scope of the current platform

AcaSift compares documents stored in its internal reference repository. It does not currently search the entire internet or every academic publication database.
